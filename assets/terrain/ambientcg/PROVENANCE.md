# ambientCG terrain material library

Owner-selected geography texture candidates, October 29, 2026.

Provider: ambientCG, Lennart Demes. License: CC0 1.0 Universal.
Official license: https://docs.ambientcg.com/license/
The fetched license statement is preserved in `license_source.html`.
CC0 permits use, modification, and redistribution, including commercial use.

Thirteen materials were selected for original 2K JPG packages:

- Grass001, Grass004, Grass005
- Ground019, Ground037, Ground048, Ground054
- Rock020, Rock028, Rock029, Rock030, Rock035, Rock051

Download status: all thirteen sets downloaded and archive-verified successfully.
The paving screenshots remain unidentified and are not part of this library.

`manifest.json` records individual asset pages, download URLs, archive sizes,
archive SHA-256 hashes and extracted file hashes. Archives are checked for CRC
errors before extraction. The original package files, including any supplied
license metadata, are retained in each material folder; ZIP copies are not kept.
Reproduce with `python tools/download_ambientcg_terrain.py` from the project root.
Network access is required.

All thirteen color maps now supply the runtime terrain palette through
`resources/terrain_palette.res`: 512px RGB layers with mipmaps, generated by
`tools/bake_terrain_palette.gd` in the manifest's material order. The compressed
resource is about 10.7 MiB (about 13 MiB uncompressed RGB mipmapped image data).
Source assets remain intact. The palette is shared by close and distant terrain;
biome tinting and restrained contrast retain the painterly visual direction.
Final owner art acceptance and device performance acceptance remain open.
No displacement is applied by this download. The two paving screenshots supplied
after selection remain unidentified and are not included in these thirteen sets.

Binary sizes must be reviewed before staging or publishing. No Git LFS adoption
or remote publication is performed by the downloader.
