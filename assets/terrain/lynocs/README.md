# Lynocs terrain textures

Source is [Texture Pack by Lynocs](https://lynocs.itch.io/texture-pack), marked
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) by the author.

Each material pairs the archive's `diffuseOriginal` and `normal` maps. The maps
were resized from 1024 to 512 pixels and stored as PNG for the game.

| Biome | Archive and variant |
| --- | --- |
| Coast | Beach 7 for the damp fringe, Sand 5 for the dry beach |
| Meadow | Grass 5 |
| Heath | Sand 5 |
| Jungle | Ground 8 |
| Desert | Desert 4 |
