# Encounter initiation for the first prototype

Owner decision, October 27, 2026: support player-initiated encounters plus warned
contact with the guarding Seedmote. The existing guard posture alone had not
established hostility, so this choice was explicitly confirmed before implementation.

Apply hostility only to the third authored sighting, not every Seedmote or its
class. Preserve source warning rules: a visible warning first, then a later
completed player step into contact; warning refresh must not interrupt movement,
and retreat before contact remains possible. Player-initiated entry can target
the current available individual, including non-hostile sightings.

The current slice is a face-to-face preview with record-sighting and withdraw
choices. It does not implement tactical battle, starter selection, escape rolls,
capture, or rewards. Those require the corresponding source/Bible reconciliation
and implementation. Prototype entry/withdrawal tuning remains adjustable in Godot.
See [implementation and limits](../encounter-initiation.md).
